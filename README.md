# Prueba Técnica KS2 - Gestión de Inmuebles (Fullstack)

Este repositorio contiene la solución a la prueba técnica para el sistema de Gestión de Inmuebles. 
El proyecto está dividido en dos partes principales: el **Backend** (API RESTful) y el **Frontend** (Aplicación web).

## Arquitectura General del Proyecto

- **`/backend`**: Desarrollado con NestJS, Prisma (v7.9+) y PostgreSQL. Sigue estrictamente principios de **Clean Architecture**, **Domain-Driven Design (DDD)** y Arquitectura Hexagonal. 
- **`/frontend`**: Desarrollado con tecnologías modernas de React (próximamente en desarrollo).

## Requisitos Previos

- **Node.js** (v18 o superior)
- **PostgreSQL** (Base de datos relacional en funcionamiento local o remoto)
- `npm`, `pnpm` o `yarn` instalados.
